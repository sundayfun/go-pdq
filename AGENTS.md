# Repository instructions

For every Go coding, review, debugging, or setup task, load the
`cc-skills-golang:golang-how-to` skill and the task-specific Go skills it
selects. Use the Modern Go Guidelines CLI before editing Go files.

Keep this repository a small importable library. Algorithm compatibility,
input normalization, quality calculation, and dihedral transforms belong
here; application-specific matching thresholds and persistence do not.
